# PetTracker

个人宠物定位与远程监控系统。

## 1. 项目简介

PetTracker 是一个用于个人学习和实践的宠物定位项目。

项目计划从软件模拟开始，逐步实现定位数据生成、后端接收、数据库存储、网页地图展示，以及真实 GPS 硬件接入。

项目的主要目标是通过一个完整的实践项目，学习和巩固 C/C++、Python、网络通信、数据库、前端开发、嵌入式开发和软件工程知识。

## 2. 项目目标

- [ ] 实现模拟 GPS 定位数据生成
- [ ] 搭建后端 API 服务
- [ ] 使用数据库保存定位历史
- [ ] 开发手机和电脑均可访问的网页
- [ ] 在地图上显示当前位置和历史轨迹
- [ ] 接入真实 GPS/GNSS 模块
- [ ] 实现独立设备的远程数据上报
- [ ] 完善设备状态监控和异常处理

## 3. 技术路线

- 设备端：C/C++，后续使用 ESP32 和 GPS/GNSS 模块
- 后端：Python、FastAPI
- 数据库：SQLite 起步，后续评估 PostgreSQL
- 前端：HTML、CSS、JavaScript
- 工程管理：Git、GitHub、VS Code

## 4. 系统架构

GPS/GNSS 模块获取定位数据，由设备程序读取并通过网络发送到服务器。

服务器负责数据校验、定位历史存储和 API 服务。

前端通过 API 获取定位信息，并在地图上展示当前位置和历史轨迹。

第一阶段使用软件生成模拟定位数据，不依赖真实硬件。

## 5. 开发计划

- V0.1：模拟定位数据与基础开发环境
- V0.2：后端 API 与数据库
- V0.3：网页和地图展示
- V0.4：真实 GPS/GNSS 数据接入
- V0.5：独立设备与远程通信
- V1.0：整合、测试与文档完善
