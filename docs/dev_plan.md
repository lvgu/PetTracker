特别是网络基础，你之前做过 C/C++，所以我建议重新梳理 TCP、UDP、HTTP、DNS、端口、客户端与服务器、同步与异步通信。这些知识会贯穿设备和服务器之间的所有交互。

真正用于宠物的定位器，通常需要三个核心部分：
- 定位模块： 获取经纬度。GPS 是 GNSS 的一种，实际模块可能同时支持多个卫星导航系统。
- 主控： 运行程序、解析定位数据并管理通信。
- 通信模块： 通过蜂窝网络把位置传到远程服务器。
另外还要有电池、电源管理、天线，以及最终的外壳。
我建议的采购顺序是：
1. 先用电脑模拟定位数据。
2. 购买一个 USB GPS 接收器或适合开发的 GNSS 模块，完成真实数据读取。
3. 购买 ESP32 开发板，学习嵌入式开发。
4. 确认实际使用地区的蜂窝网络覆盖后，再选 LTE Cat.1 等通信模块。
5. 最后考虑电池和外壳。
